# Projet Vulkan : cube texturé en rotation

Rendu 3D en C++ utilisant l'API graphique Vulkan. Il ouvre une fenêtre redimensionnable et y affiche un cube texturé en rotation.

À installer avant de compiler :

- **Un compilateur C++** compatible C++20
- **Le SDK Vulkan** (LunarG), qui fournit les en-têtes
- **stb_image.h** pour charger la texture

### Code C++

1. Ouvrir le projet dans l'IDE.
2. Vérifier que les dossiers d'en-têtes et de bibliothèques du SDK Vulkan, de GLFW et de GLM sont bien configurés.
3. Vérifier que `stb_image.h` est accessible depuis le projet.
4. Choisir la configuration **Debug** ou **Release**, puis compiler.
